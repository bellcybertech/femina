# 🎉 FEMINA 2026 – Poster Generator

A simple web application that allows users to generate a personalized poster for the FEMINA 2026 event using their name, role, and photo.

---

## 🚀 Features

* Enter name and role
* Upload a personal photo
* Generate a customized poster
* Download the poster as PNG
* Share on WhatsApp, Facebook, Twitter/X, Telegram

---

## 📁 Project Structure

📦 femina-poster-generator
┣ index.html
┣ fond_card.jpg (IMPORTANT)
┗ README.md

---

## ⚙️ Usage

1. Open `index.html` in your browser
2. Make sure `fond_card.jpg` is in the same folder
3. Fill the form
4. Click Generate
5. Download or share your poster

---

## ⚠️ Important

* The file `fond_card.jpg` must be in the same folder as `index.html`
* Click **Generate** before downloading
